# Data Directory

## `processed/`
Contains only the wall-level metrics that are internally consistent across the manuscript figures and conclusions:

- average grain size (µm)
- average Vickers hardness (HV10)

## `metadata/`
Contains experimental setup, wall-strategy, and test-matrix metadata. Exact energy-input values and orientation-resolved tensile results are intentionally not released here pending reconciliation with the original laboratory files.

## `raw/`
Reserved for original machine logs, load-displacement files, stress-strain exports, individual hardness indents, Charpy records, and full-resolution microscopy. The folder is empty in the public release.
