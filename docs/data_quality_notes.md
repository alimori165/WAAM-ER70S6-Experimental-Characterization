# Data Quality Notes

This release follows a conservative evidence policy. The goal is to present a credible experimental portfolio without amplifying manuscript inconsistencies.

## Included in quantitative highlights

- Average grain size for W1-W3: 25.3, 30.8, and 44.4 µm.
- Average Vickers hardness for W1-W3: 176, 161, and 149 HV10.

These values are consistent between the manuscript graphs, discussion, and conclusions.

## Withheld from public quantitative highlights

1. **Exact heat-input values** - the abstract, body, and process table do not provide a single reconciled set, and the reported electrical/travel parameters require checking against original machine logs.
2. **Elongation values** - values are presented numerically as approximately 0.27-0.38 while labelled as percent, whereas the narrative describes roughly 30%; raw tensile exports are needed to resolve fraction-versus-percent representation.
3. **Tensile toughness values** - the calculation definition and reported unit are not sufficiently documented for public reuse.
4. **Fracture toughness estimates** - values derived from an empirical Charpy correlation must not be described as directly measured ASTM fracture toughness.
5. **Orientation-specific UTS and YS highlights** - orientation labels and values differ across manuscript sections; release requires specimen-ID and machine-export verification.
6. **Cooling-rate and Δt8/5 values** - these appear to be analytical/model-derived estimates rather than directly released thermal-history measurements and are therefore not treated as raw experimental observations here.

## Interpretation rule

Because W1 uses a different bead strategy from W2 and W3, trends should be attributed to the overall **deposition condition** unless a controlled re-analysis demonstrates an isolated heat-input effect.
