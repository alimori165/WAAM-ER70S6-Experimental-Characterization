# Data and Image Use

This repository contains a curated public summary of an experimental study and selected figures from an unpublished/under-review manuscript.

- No permission is granted to redistribute the source images or unpublished numerical data without written approval from the corresponding author.
- The generated plots and repository code may be reused for non-commercial research with attribution.
- Raw tensile, impact, hardness-indentation, and high-resolution microscopy files are not part of this release.
